IMPORT PATTERNS
===============

PACKAGES
--------
@keenmate/web-dropzone        renderer: 5 custom elements + CSS; bundles the core
@keenmate/web-dropzone-core   headless store (DropzoneEngine), types, helpers

Runtime dependency of both: @keenmate/web-components-core (BlissElement,
/logging, /positioning, which pulls @floating-ui/dom).

| You want                                   | Install                      |
|--------------------------------------------|------------------------------|
| <web-dropzone> and/or satellites in a page | @keenmate/web-dropzone       |
| Your own React/Vue/Svelte renderer, no CE  | @keenmate/web-dropzone-core  |
| Built-in elements + a custom satellite     | @keenmate/web-dropzone only  |
                                               (it re-exports core types/helpers)

SIDE-EFFECT IMPORT (REGISTERS ELEMENTS)
---------------------------------------
import '@keenmate/web-dropzone';

Defines web-dropzone, web-dropzone-picker, web-dropzone-list,
web-dropzone-indicator, web-dropzone-progress. Registration order is
handled internally (satellites before the store). Re-importing is a no-op
(guarded by customElements.get).

HEADLESS CORE
-------------
import { DropzoneEngine } from '@keenmate/web-dropzone-core';

const host = document.createElement('div');
document.body.appendChild(host);

const engine = new DropzoneEngine(host, {
  isMultiple: true,
  maxFileCount: 10,
  uploadFileCallback: async ({ file, signal, setProgress }) => { /* ... */ }
});

const store = engine.controller;          // DropzoneController
host.addEventListener('files-change', (e) => render(e.detail.files));

The engine dispatches the same events (bubbling, not composed) on `host`;
`element` in every ctx/detail is `host`. Config keys are the camelCase
DropzoneConfig names (isMultiple, not multiple).

STYLES
------
Shadow DOM: CSS is inlined into each shadow root by the JS bundle. Nothing to
import for the component itself. Package exports for tooling:

@keenmate/web-dropzone/style.css      compiled CSS (dist/style.css)
@keenmate/web-dropzone/css            src/css/main.css (source entry)
@keenmate/web-dropzone/src/css/*      individual partials (no "_" prefix)
@keenmate/web-dropzone/manifest       component-variables.manifest.json
                                      (--base-* consumed / --dz-* exposed)

CDN / SCRIPT TAG
----------------
<script type="module" src=".../node_modules/@keenmate/web-dropzone/dist/dropzone.js"></script>

UMD build: dist/dropzone.umd.js (package "main"); the module build is
dist/dropzone.js ("module"/"import").

GLOBAL API
----------
On load the package publishes window.components['web-dropzone']:

window.components['web-dropzone'].version()      // package version
window.components['web-dropzone'].config         // { name, version, author, license,
                                                 //   repository, homepage, core:{name,version} }
window.components['web-dropzone'].logging        // enableLogging, disableLogging,
                                                 // setLogLevel, setCategoryLevel, getCategories
window.components['web-dropzone'].register()     // define <web-dropzone> if not yet defined
window.components['web-dropzone'].getInstances() // connected <web-dropzone> elements

FRAMEWORKS
----------
React (19+ passes properties to custom elements; for older React use a ref):

const ref = useRef(null);
useEffect(() => {
  const dz = ref.current;
  dz.uploadFileCallback = upload;
  const onChange = (e) => setFiles(e.detail.files);
  dz.addEventListener('change', onChange);
  return () => dz.removeEventListener('change', onChange);
}, []);
return <web-dropzone ref={ref} display-mode="list" />;

Vue: register as custom element (compilerOptions.isCustomElement:
tag => tag.startsWith('web-dropzone')); bind properties with .prop:
<web-dropzone display-mode="grid" :uploadFileCallback.prop="upload" @change="onChange" />

Svelte / Lit: set properties directly (Lit: .uploadFileCallback=${fn}).

Framework-rendered UI: use render-mode="headless" and render from `files-change`
(rAF-coalesced snapshot). See examples-react.html / examples-vue.html and
advanced-patterns.txt.

TYPESCRIPT ELEMENT TYPING
-------------------------
const dz = document.querySelector('web-dropzone') as DropzoneElement;

Or declare it once:
declare global {
  interface HTMLElementTagNameMap { 'web-dropzone': DropzoneElement }
}
(the package does not ship this augmentation itself)
