LABELS & I18N
=============

EVERY UI string the dropzone and its satellites render by themselves comes
from ONE input: `labels`. It is a PARTIAL object merged per
key over the built-in English DEFAULT_LABELS. Placeholders in {braces} are
filled at render time.

Keys are FLAT `<elementType>.<name>` (core /locale): the element type says
where the text is SHOWN - buttons (visible caption), tooltips (title),
ariaLabels (screen-reader only: aria-label, live announcements), headers,
labels (other visible text), messages (empty state / progress), errors
(validation / failure). A text shown on two surfaces has two keys sharing
the name (ariaLabels.cancelFile + tooltips.cancelFile). The FULL key
prefixes the component: web-dropzone.buttons.selectFiles; `labels` takes the
short or the full key.

SETTING LABELS
--------------
Property (object):
dz.labels = { 'ariaLabels.cancelFile': 'Zrusit {name}', 'labels.prompt': 'Pretahnete soubory sem' };

Attribute (JSON object of strings):
<web-dropzone display-mode="list"
  labels='{"labels.prompt":"Drop invoices here","labels.hint":"PDF up to 10 MB","buttons.selectFiles":"Browse"}'>
</web-dropzone>

- Per-key merge: keys you omit keep their English default.
- Live: changing labels re-renders the element and its satellites.
- A malformed attribute (not JSON, or any non-string value) warns and keeps
  the previous value. Absent / empty attribute -> built-in English.
- Assigning a new object replaces the previous overrides (no deep merge with
  the previous object) - spread it yourself:
    dz.labels = { ...dz.labels, 'ariaLabels.retryFile': 'Znovu {name}' };

ALL KEYS AND DEFAULTS
---------------------
Prompt / selector:
  labels.prompt         'Drop files here or click to browse'   card prompt text; names the card input
                                                               (aria-labelledby)
  ariaLabels.prompt     'Drop files here or click to browse'   icon-only minimal selector name; card input
                                                               with a renderPromptCallback prompt.
                                                               Unset = follows a customized labels.prompt
  labels.hint           ''   secondary line under the prompt. Empty = none on the card;
                             the compact popover then derives a limits line
  labels.dragActive     'Drop files here'      card text while a drag is over it
  buttons.selectFiles   'Select files'         button / native selector, big-card browse button
  labels.noFileChosen   'No file chosen'       native selector when empty
  labels.filesChosen    '{count} files chosen' native selector, 2+ files
  labels.overlay        'Drop files here'      drag-overlay text (overlay-target)

Status names (status pill / indicator icon tooltip; {status} in ariaLabels.status):
  labels.statusPending     'Pending'
  labels.statusUploading   'Uploading'
  labels.statusPaused      'Paused'
  labels.statusCancelling  'Cancelling…'
  labels.statusComplete    'Complete'
  labels.statusError       'Error'
  labels.statusCancelled   'Cancelled'
  labels.cancelTimeout     'Cancel timed out'   status name of an error file whose cancel
                                                timed out (file.error === 'cancel-timeout')
  ariaLabels.status        'Status: {status}'   pill / summary icon aria-label
  ariaLabels.uploading     'Uploading'          indicator upload loader aria-label
  messages.cancelling      'Cancelling…'        text next to the bar while a cancel waits

Row buttons ({name} = file name):
  ariaLabels.pauseFile  / tooltips.pauseFile    'Pause {name}'
  ariaLabels.resumeFile / tooltips.resumeFile   'Resume {name}'
  ariaLabels.retryFile  / tooltips.retryFile    'Retry {name}'
  ariaLabels.cancelFile / tooltips.cancelFile   'Cancel {name}'
  ariaLabels.removeFile                         'Remove {name}'

Bulk actions (overall-progress strip / <web-dropzone-progress>):
  buttons.pauseAll     'Pause all'
  buttons.resumeAll    'Resume all'
  buttons.retryAll     'Retry all'
  buttons.cancelAll    'Cancel all'

List / popover:
  messages.noData        'No files selected'          empty file list
  labels.summary         '{count} file(s), {size}'    compact summary line
  ariaLabels.viewFiles   'Click to view files'        summary line aria-label
  labels.fileCount       '{count} files'              popover header / footer
  labels.fileCountOne    '1 file'
  buttons.addMore        'Add more'                   popover header
  buttons.clearAll       'Clear all'                  popover header
  ariaLabels.close       'Close'                      popover / drawer close button
  buttons.showMore / ariaLabels.showMore   'Show {count} more'   max-visible-file-count
                         toggle: text caption / the "+N" badge's aria-label
  buttons.showLess / ariaLabels.showLess   'Show less'
  ariaLabels.showQueue / tooltips.showQueue  'Show all {count} files'  rolling queue button
  labels.unknownType     'Unknown'                    type column without a MIME type

Popover limits line (used when labels.hint is empty; joined with " · "):
  labels.limitMaxFileSize       'max {size} each'
  labels.limitMinFileSize       'min {size} each'
  labels.limitMaxTotalSize      'up to {size} total'
  labels.limitMaxTotalSizeLeft  'up to {size} total · {left} left'
  labels.limitMaxFileCount      'up to {count} files'
  labels.limitMaxFileCountLeft  'up to {count} files · {left} left'
  labels.limitMinFileCount      'at least {count} files'

Progress strip (overall progress / <web-dropzone-progress>):
  messages.progressCounts  '{completed} of {total} · {uploadedSize} / {totalSize}'
  messages.progressPaused  '{count} paused'
  messages.progressFailed  '{count} failed'

Indicator (<web-dropzone-indicator>):
  headers.indicator           'Uploads'        drawer title + the drawer dialog's name (aria-labelledby)
  ariaLabels.indicatorStatus  'Upload status'  chip aria-label
  messages.indicatorIdle      'No uploads'     chip text with nothing queued
  messages.indicatorFailed / indicatorUploading / indicatorPaused / indicatorQueued /
  indicatorDone  '{count} failed' / '{count} uploading' / ... / '{count} done'

Validation (file-reject validation.error, form validity):
  errors.maxFileSize      'File is too large. Maximum size is {size}'
  errors.minFileSize      'File is too small. Minimum size is {size}'
  errors.fileType         'File type not accepted'
  errors.rejected         'File rejected'            (beforeFilesAddCallback said false)
  errors.maxFileCount     'Maximum {count} files allowed'
  errors.maxFileCountOne  'Maximum 1 file allowed'
  errors.duplicate        'Duplicate file: {name}'
  errors.maxTotalSize     'Total size would exceed {size}'
  errors.upload           'Upload failed'            (handler threw a non-Error)
  errors.minFileCount     'At least {count} files required'   (min-file-count validity)
  errors.minFileCountOne  'At least 1 file required'

Screen-reader announcements (core announce(); '' silences one):
  ariaLabels.announceAdded(One), ariaLabels.announceRejected,
  ariaLabels.announceUploadDone(One), ariaLabels.announceUploadFailed,
  ariaLabels.announceRemoved
`...One` keys are used when the count is exactly 1 (countLabel(label, key, n)).

PLACEHOLDERS
------------
{name}    file name (row buttons, errors.duplicate)
{status}  a status name (ariaLabels.status)
{count}   a number (labels.summary, labels.fileCount, buttons.showMore, limits, indicator, errors)
{size}    a formatted size ('5.0 MB') (summary, limits, size errors)
{left} / {completed} / {total} / {uploadedSize} / {totalSize}  see the keys above
Unknown placeholders are left as written. Only the keys above are looked up.

THE resolveLabel SEAM
---------------------
Every lookup goes through one function:

import { resolveLabel, DEFAULT_LABELS, createLabelFn } from '@keenmate/web-dropzone';

resolveLabel(sources, key, vars?)
  sources = one labels object or an array (most specific first: a satellite's
  own labels, then its store's); the first that has key wins ->
  window.components.locale.labels['web-dropzone.<key>'] -> DEFAULT_LABELS[key],
  then {placeholders} filled from vars.

resolveLabel({ 'ariaLabels.cancelFile': 'Stop {name}' }, 'ariaLabels.cancelFile', { name: 'a.pdf' })  // 'Stop a.pdf'
resolveLabel(null, 'ariaLabels.status', { status: 'Paused' })                                     // 'Status: Paused'

const label = createLabelFn(() => dz.labels);    // bound lookup, reads live
label('buttons.retryAll');

Use these in custom satellites / render callbacks so your UI matches the
element's language.

PAGE-WIDE (core /locale)
------------------------
window.components.locale = {
  locale: 'cs-CZ',
  labels: {                                         // ONE flat dictionary of full keys
    'web-dropzone.labels.prompt': 'Přetáhněte soubory sem',
    'web-dropzone-indicator.headers.indicator': 'Fronta',   // that satellite only
  },
  translateCallback: ({ key, params }) => (i18next.exists(key) ? i18next.t(key, params) : null),
};
translateCallback gets the FULL key; null / undefined = not mine. It is never
asked for a key the instance set in its own labels.

Also exported from @keenmate/web-dropzone-core: defaultLabel, statusLabel(label,
status), fileStatusLabel(label, file) (returns labels.cancelTimeout for timed-out
cancels), isLabelsValue(value), types DropzoneLabels, DropzoneLabelKey,
DropzoneLabelOverrides,
LabelFn, LabelVars.

SATELLITES
----------
Satellites read the BOUND STORE's labels. Every satellite also takes its OWN
`labels` (property or JSON attribute), merged per key ON TOP of the store's:
  <web-dropzone-picker for="dz" labels='{"labels.prompt":"Drop invoices","labels.hint":"PDF only"}'>
  <web-dropzone-picker for="dz" selector-appearance="button" labels='{"buttons.selectFiles":"Browse"}'>
  <web-dropzone-list for="dz" labels='{"messages.noData":"Nothing yet"}'>
  <web-dropzone-indicator for="dz" labels='{"headers.indicator":"Queue"}'>
  picker.labels = { 'labels.noFileChosen': 'Nic' };   // live
