TYPESCRIPT TYPES
================

Types live in @keenmate/web-dropzone-core; the renderer package re-exports
the common ones. Use `import type`.

import type {
  DropzoneConfig, DropzoneController, FileState, FileStatus,
  FileUploadContext, FileUploadResult, FileCancelEventDetail, DropzoneEventMap
} from '@keenmate/web-dropzone';
import { DropzoneElement } from '@keenmate/web-dropzone';

ELEMENT
-------
class DropzoneElement extends BlissElement<DropzoneEventMap, DropzoneController>
  readonly controller: DropzoneController       // from BlissElement
  readonly files: FileState[]
  readonly form: HTMLFormElement | null          // from BlissElement
  multiple, disabled, filesInside, autoUpload, uploadedDeletable: boolean
  showThumbnails: boolean | undefined
  displayMode: DisplayMode
  selectorAppearance: SelectorAppearance | null
  listAppearance: ListAppearance | null
  gridLayout: GridLayout | null; gridStatus: GridStatus | null
  rollingRotation: RollingRotation; cardSize: CardSize | null
  valueFormat: ValueFormat
  overlayTarget: HTMLElement | string | null
  labels: Partial<DropzoneLabels> | null
  // + one accessor per input configKey (accept, maxFileSize, uploadFileCallback, ...)
  // + on* twins: onFileAdd, onFileRemove, onFilesChange, onChange, onFilesReject,
  //   onFileRetry, onFileUploadComplete, onFileDelete, onFileCancel,
  //   onFileProgress, onFileStatusChange, onFileUpdate, onOverlayEnter,
  //   onOverlayLeave, onReady   -> ((detail) => void) | null
  addFiles(files: FileList | File[]): Promise<void>
  removeFile(id: string, opts?: { confirm?: boolean }): Promise<void>
  removeFiles(ids: readonly string[], opts?: { confirm?: boolean }): Promise<void>
  clear(opts?: { confirm?: boolean }): Promise<void>
  getFile(id: string): FileState | undefined
  updateFileProgress(id: string, progress: number): void
  setFileStatus(id: string, status: FileStatus, error?: string): void
  uploadAll(): Promise<void>; uploadFile(id: string): Promise<void>
  pauseFile(id: string): void; pauseAll(): void
  resumeFile(id: string): Promise<void>; resumeAll(): Promise<void>
  cancelFile(id: string): Promise<void>; cancelAll(): Promise<void>
  retryFile(id: string): void; retryAll(): void
  destroy(): void
  // BlissElement: whenSettled(): Promise<void>; flush(): void;
  //   setAttributes(values: Record<string, unknown>): void; batch(fn): void

Note: element addFiles has no opts; Mode B opts go through
el.controller.addFiles(files, opts).

IMPORTANT: the per-input accessors (accept, maxFileSize, uploadFileCallback,
retryPolicy, cancelTimeout, beforeFileCancelCallback, ...) exist at runtime
(installed by core from the input table) but are NOT declared on
DropzoneElement's TypeScript type - only the aliases/enums listed above are.
In TS, either widen the type or use setAttributes:

type DropzoneInputs = Partial<Omit<DropzoneConfig, 'container' | 'hostElement' | 'isHeadless'>>;
const dz = document.querySelector('web-dropzone') as DropzoneElement & DropzoneInputs;
dz.uploadFileCallback = upload;

dz.setAttributes({ uploadFileCallback: upload, maxFileCount: 5 });  // untyped record

DropzoneController
------------------
interface DropzoneController {
  readonly isReady: boolean;
  addFiles(files: FileList | File[], opts?: AddFilesOptions): Promise<void>;
  removeFile(id: string, opts?: { confirm?: boolean }): Promise<void>;
  removeFiles(ids: readonly string[], opts?: { confirm?: boolean }): Promise<void>;
  clear(opts?: { confirm?: boolean }): Promise<void>;
  getFiles(): FileState[];                    // a copy
  getFile(id: string): FileState | undefined;
  getConfig(): Readonly<DropzoneConfig>;
  getOverallProgress(): OverallProgress;
  updateFileProgress(id: string, progress: number): void;
  setFileStatus(id: string, status: FileState['status'], error?: string): void;
  uploadAll(): Promise<void>;  uploadFile(id: string): Promise<void>;
  pauseFile(id: string): void; resumeFile(id: string): Promise<void>;
  cancelFile(id: string): Promise<void>; retryFile(id: string): void;
  pauseAll(): void; cancelAll(): Promise<void>;
  resumeAll(): Promise<void>; retryAll(): void;
}
Built once, delegates to the live store (survives rebuilds). Before the store
is built: reads return empty defaults, mutators are no-ops.
createDropzoneController(getTarget) (core) builds one for custom hosts.

FILE STATE
----------
type FileStatus = 'pending' | 'uploading' | 'complete' | 'error'
                | 'paused' | 'cancelling' | 'cancelled';

interface FileState {
  id: string; file: File; name: string; size: number; type: string;
  status: FileStatus; progress: number; error?: string;
  previewUrl?: string; downloadUrl?: string;
  metadata?: Record<string, unknown>;
  uploadFileCallback?: FileUploadHandler;      // Mode B (stamped by a picker)
  uploadMetadata?: Record<string, unknown>;    // Mode B
}

interface FileUploadResult { metadata?: Record<string, unknown>; downloadUrl?: string;
                             previewUrl?: string; name?: string; }
type FileUploadHandler = (ctx: FileUploadContext) => Promise<void | FileUploadResult>;
interface AddFilesOptions { uploadFileCallback?: FileUploadHandler;
                            uploadMetadata?: Record<string, unknown>; }
interface RetryPolicy { attempts?: number; delayMs?: number; backoff?: number; }
type ProgressMode = 'optimistic' | 'pessimistic';
type CancelTimeoutBehavior = 'error' | 'remove';
type FileCancelResult = 'cancelled' | 'timeout-error' | 'timeout-remove';

interface ValidationResult { valid: boolean; error?: string;
  code?: 'size' | 'type' | 'count' | 'duplicate' | 'custom' | 'rejected'; }
interface RejectedFile { file: File; validation: ValidationResult; }
type DedupeMode = 'name' | 'name-size' | 'none';

interface OverallProgress {
  uploadedBytes: number; totalBytes: number; percent: number;
  completedCount: number; failedCount: number; uploadingCount: number;
  pausedCount: number; pendingCount: number; cancellingCount: number;
  hasActivity: boolean; aggregateStatus: 'uploading' | 'paused' | 'error' | 'complete';
}

interface DropzoneState { popoverWidth?: number; popoverHeight?: number; }

EVENT DETAILS
-------------
type DropzoneEventMap = {
  'file-add': FileAddEventDetail;                 // { file: FileState }
  'file-remove': FileRemoveEventDetail;           // { file }
  'files-change': FilesChangeEventDetail;         // { changedIds: string[]; files }
  'change': ChangeEventDetail;                    // { files }
  'files-reject': FilesRejectEventDetail;         // { rejectedFiles: RejectedFile[] }
  'file-retry': FileRetryEventDetail;             // { file }
  'file-upload-complete': FileUploadCompleteEventDetail; // { file }
  'file-delete': FileDeleteEventDetail;           // { file }
  'file-cancel': FileCancelEventDetail;           // { file; result: FileCancelResult;
                                                  //   uploadedBytes: number;
                                                  //   metadata: Record<string, unknown> | undefined }
  'file-progress': FileProgressEventDetail;       // { id; progress; status; file }
  'file-status-change': FileStatusChangeEventDetail; // { id; prevStatus; nextStatus; file }
  'file-update': FileUpdateEventDetail;           // { file }
  'overlay-enter': OverlayEventDetail;            // { overlayElement: HTMLElement }
  'overlay-leave': OverlayEventDetail;
  'ready': ReadyEventDetail;                      // = DropzoneContext
};
type DropzoneListEventMap = { 'summary-activate': SummaryActivateEventDetail;
                              'queue-open': QueueOpenEventDetail };   // both = DropzoneContext
FileRowUpdateEventDetail { file: FileState }  (+ context)

Typed listener helper:
function on<K extends keyof DropzoneEventMap>(el: HTMLElement, name: K,
    fn: (detail: DropzoneEventMap[K]) => void) {
  el.addEventListener(name, (e) => fn((e as CustomEvent<DropzoneEventMap[K]>).detail));
}
on(dz, 'file-cancel', ({ result, metadata }) => { /* typed */ });

DropzoneConfig
--------------
The camelCase config object (DropzoneEngine constructor / getConfig()).
Keys = the element's input configKeys: isMultiple, accept, maxFileSize,
minFileSize, maxTotalSize, maxFileCount, minFileCount, maxVisibleFileCount,
dedupeMode, isDisabled, mode, progressThrottle, displayMode,
selectorAppearance, listAppearance, gridLayout, gridStatus, controls,
itemControls, rollingRotation, cardSize, isThumbnailsShown,
isFilesInside, icon, labels, emptyMessage, summaryTemplate,
popoverPlacement, overlayTarget, overlayIcon, name, valueFormat, every
*Callback, fileIcons, concurrency, shouldAutoUpload, progressMode,
retryPolicy, cancelTimeout, cancelTimeoutBehavior, cancelIcon, removeIcon,
isUploadedFileRemovalAllowed, shouldSinkCompleted, sinkCompletedDelay,
storageKey. Internal: isHeadless (derived from mode), container, hostElement.
(shouldKeepAliveWhenRemoved is an element-only input.)
