DOCUMENTATION INDEX
===================

AI reference for <web-dropzone> (@keenmate/web-dropzone) and its satellites.
Quick reference for finding documentation on specific topics.

FILE OVERVIEW
-------------
basic-setup.txt          - Install, first dropzone, mode inference, methods, properties
import-patterns.txt      - Packages, imports, headless core, styles, global API, frameworks
display-modes.txt        - mode, selector/list appearances, display-mode shorthand,
                           grid, files-inside, compact popover, rolling, controls,
                           item-controls, Cancel vs Remove, drag overlay
custom-rendering.txt     - render-mode="structural" render callbacks, file-row-update,
                           file icons, raw-HTML inputs, getCustomStylesCallback
upload-pipeline.txt      - uploadFileCallback ctx, concurrency, auto-upload, pause /
                           resume / retry / cancel rule, retryPolicy, progress-mode,
                           progress-throttle, removal teardown, server cleanup
validation.txt           - accept, size/count caps, dedupe-mode, validateCallback,
                           beforeFilesAddCallback, file-reject codes, min-file-count
labels-i18n.txt          - the labels input: every key + default, placeholders,
                           JSON attribute, resolveLabel seam
events-callbacks.txt     - event table, on* twins, ctx/detail context, gates,
                           file-cancel / file-delete
satellites.txt           - picker / list / indicator / progress, for= binding,
                           Mode A/B, status-surface callbacks, custom satellites
form-integration.txt     - form association, File blobs, min-file-count validity,
                           reset, fieldset disabled, upload-then-submit
keyboard-navigation.txt  - keyboard support and accessibility as implemented
styling-theming.txt      - --dz-* variables, --dz-rem, --base-* layer, dark mode,
                           parts, managed satellites
rtl-support.txt          - right-to-left layout
logging-debugging.txt    - DROPZONE:* loggers, global API, troubleshooting
typescript-types.txt     - element, controller, FileState, contexts, event map
advanced-patterns.txt    - headless + frameworks, Mode B, persistence, resumable
                           uploads, recipes, lifecycle, custom satellites
migration-guide.txt      - rc02 -> rc03 (breaking), rc01 -> rc02, pre-rc -> rc01
