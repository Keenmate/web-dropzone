RTL SUPPORT
===========

Right-to-left layout for Arabic, Hebrew, Persian, etc.

ENABLING
--------
Put dir="rtl" ON THE ELEMENT:

<web-dropzone dir="rtl" display-mode="detailed"></web-dropzone>

The explicit RTL rules in rtl.css are keyed on :host([dir="rtl"]), i.e. the
`dir` attribute of the element itself (<web-dropzone>, or a standalone
satellite such as <web-dropzone-list dir="rtl">).

Inherited direction: CSS `direction` inherits into shadow roots, so text and
normal flex rows already follow an ancestor's dir="rtl" (row order, text
alignment) without the attribute. The :host([dir="rtl"]) rules are NOT applied
in that case. Test your layout both ways; if an ancestor is RTL, prefer also
setting dir on the dropzone (or omit it and rely on native bidi) - whichever
renders correctly for your appearance.

WHAT rtl.css FLIPS
------------------
.dz__file-item--list / --detailed   flex-direction: row-reverse
.dz__file-item-info                text-align: right
.dz__file-item-meta                flex-direction: row-reverse
.dz__preview-item-remove           moves from the right to the left corner
.dz__popover-header                flex-direction: row-reverse
.dz__popover-cell--name            text-align: right
.dz__popover-cell--size            text-align: left
.dz__summary-line                  flex-direction: row-reverse

Note: row-reverse on top of an inherited RTL `direction` reverses twice
(back to LTR order) for those containers. If rows look mirrored the wrong
way with dir on the host, check which direction the host actually computes.

SATELLITES
----------
Each satellite has its own shadow root and its own :host. Put dir on each
standalone satellite you want flipped:

<div dir="rtl">
  <web-dropzone id="s" dir="rtl"></web-dropzone>
  <web-dropzone-picker for="s" dir="rtl"></web-dropzone-picker>
  <web-dropzone-list for="s" dir="rtl" list-appearance="detailed"></web-dropzone-list>
</div>

Satellites mounted internally by bulk-mode <web-dropzone> do not copy the
host's dir attribute; they inherit `direction` only.

POPOVER
-------
The compact popover is positioned with floating-ui. popover-placement
"bottom-start" means start in the PHYSICAL sense of floating-ui's placement
(left edge). In RTL you may want:

<web-dropzone dir="rtl" display-mode="compact" popover-placement="bottom-end"></web-dropzone>

INDICATOR
---------
position="right" / "left" are physical edges. Choose explicitly for RTL:
<web-dropzone-indicator for="s" position="left"></web-dropzone-indicator>

TEXT
----
Translate all strings with the labels input (labels-i18n.txt). File names are
rendered as-is; mixed-direction names are handled by the browser's bidi
algorithm. Sizes are formatted as "1.5 MB" (not localized).

<web-dropzone dir="rtl" display-mode="list"
  labels='{"prompt":"اسحب الملفات هنا أو انقر للتصفح","selectFiles":"اختر الملفات","removeFile":"إزالة {name}","cancelFile":"إلغاء {name}"}'>
</web-dropzone>

CUSTOM RTL TWEAKS
-----------------
Variables are direction-agnostic. For additional rules inject CSS:

dz.getCustomStylesCallback = () => `
  :host([dir="rtl"]) .dz__overall-progress { direction: rtl; }
`;
(Bulk-mode satellites are separate shadow roots and do not receive this CSS.)
