Every UI string goes through core /locale. Keys are flat <elementType>.<name> (labels.prompt, buttons.selectFiles, ariaLabels.removeFile, errors.maxFileSize, …) — the full list is DropzoneLabels / DEFAULT_LABELS (@keenmate/web-dropzone-core). Per key: the instance labels (short or full web-dropzone. key) → the element's own translateCallback → the page-wide translateCallback → the page dictionary window.components.locale.labels → the built-in English. The validation messages (errors.*, the validation.error of file-reject) go through the same lookup. The page-wide toggles (LO02, LO03, LO05) are page-wide: they change every dropzone on this page, on purpose.

LO01 · Instance labels

Override texts on ONE element with the labels property (or a JSON labels attribute). A short key (labels.prompt, labels.hint) and a full key (web-dropzone.buttons.selectFiles) both work; every key you leave out stays English. The neighbour dropzone is untouched.

rendered strings

            

            
el.labels = {
  'labels.prompt': 'Přetáhněte soubory sem',          // short key
  'labels.hint': 'PDF nebo obrázky',
  'web-dropzone.buttons.selectFiles': 'Vybrat soubory', // full key
};
// or declaratively
<web-dropzone labels='{"labels.prompt": "Přetáhněte soubory sem"}'></web-dropzone>

        


        
        
        
        

            
LO02 · Page-wide dictionary

            

                One flat dictionary on window.components.locale.labels — the app's translation JSON as loaded,
                full keys 'web-dropzone.<elementType>.<name>', other components' keys side by side —
                translates every dropzone on the page at once, the validation messages included. Both dropzones allow
                1.5 KB per file; the readout adds a 2.5 KB report.pdf and prints the file-reject
                message. Keys an instance set itself (LO01) still win.
            

            

                
            

            

                

                    

                        
                        
                    

                    

                        
                        
                    

                

                
rendered strings + the file-reject message

            

            
// e.g. const labels = await (await fetch('/i18n/cs.json')).json();
window.components.locale = {
  labels: {
    'web-dropzone.labels.prompt': 'Přetáhněte soubory sem nebo klikněte',
    'web-dropzone.buttons.selectFiles': 'Vybrat soubory',
    'web-dropzone.errors.maxFileSize': 'Soubor je příliš velký. Maximum je {size}',
    'web-dropzone.errors.fileType': 'Tento typ souboru není povolen',
    'web-multiselect.placeholders.search': 'Hledat…',     // other components share the same JSON
  },
};
el.addEventListener('file-reject', (e) => console.log(e.detail.rejectedFiles[0].validation.error));
// → "Soubor je příliš velký. Maximum je 1.5 KB"

        


        
        
        
        

            
LO03 · translateCallback

            

                An app with its own i18n (i18next, FormatJS, …) answers keys through a callback instead of a dictionary. It gets
                { component, key, template, params, locale } — key is the full
                web-dropzone.<elementType>.<name> — and returns the text, or null = not mine.
                The element's own translateCallback is asked first (German, only labels.prompt and
                errors.maxFileSize here); its null passes the key on to the page-wide one (a small
                Slovak i18next-like lookup). A key the instance labels set (the second dropzone's
                labels.prompt) is never sent to any callback.
            

            

                
                
            

            

                

                    

                        
                        
                    

                    

                        
                        
                    

                

                
rendered strings + the file-reject message

            

            
// an i18next-like lookup: a dictionary + t(key, params)
const sk = {
  'web-dropzone.labels.prompt': 'Presuňte súbory sem',
  'web-dropzone.buttons.selectFiles': 'Vybrať súbory',
  'web-dropzone.errors.maxFileSize': 'Súbor je príliš veľký (max. {{size}})',
};
const t = (key, params) => sk[key]?.replace(/\{\{(\w+)\}\}/g, (_, p) => params?.[p] ?? '');
const exists = (key) => key in sk;

// page-wide — every component on the page
window.components.locale = { translateCallback: ({ key, params }) => (exists(key) ? t(key, params) : null) };

// one element — asked BEFORE the page-wide callback; null = not mine
el.translateCallback = ({ key, params }) => {
  if (key === 'web-dropzone.labels.prompt') return 'Dateien hier ablegen';
  if (key === 'web-dropzone.errors.maxFileSize') return `Datei zu groß (max. ${params.size})`;
  return null;
};

        


        
        
        
        

            
LO04 · Screen-reader name / tooltip follow

            

                An ariaLabels.x / tooltips.x nobody set takes the first customized key of the same
                <name>, so translating one string of a pair translates its twin. Here: translate only the
                visible prompt labels.prompt — the icon-only selector-appearance="minimal" button
                is named by ariaLabels.prompt, which nobody set, and it follows. (The same holds for the row
                buttons' tooltips.cancelFile / ariaLabels.cancelFile, … pairs.) The box below reads
                the card's prompt text and the minimal button's aria-label from the shadow roots.
            

            

                
            

            

                

                    

                        
                        
                    

                    

                        
                        
                    

                

                
visible prompt / accessible name

            

            
el.labels = { 'labels.prompt': 'Přetáhněte soubory sem' };
// → card text "Přetáhněte soubory sem" AND the minimal button's aria-label "Přetáhněte soubory sem"
//   (ariaLabels.prompt was never set); an explicitly set ariaLabels.prompt always wins over the twin

        


        
        
        
        

            
LO05 · locale + formatting

            

                File sizes ({size} in labels.summary, the limits line, the validation messages, the
                popover's size column and the progress strip) and the {count} numbers in labels use the
                element's locale input → the page window.components.locale.locale → the browser.
                Sizes are the dropzone's only locale-specific output (no dates). Below: a compact dropzone holding a
                1.3 KB file, limit 1.5 KB. The element's locale wins over the page locale; unset (or
                auto) follows it. Bound satellites follow their store's locale.

locale attribute, summary + the file-reject message

            

            
<web-dropzone display-mode="compact" max-file-size="1536"></web-dropzone>   <!-- "1 file(s), 1.3 KB" -->
<web-dropzone locale="de" display-mode="compact"></web-dropzone>           <!-- this one: "1 file(s), 1,3 KB" -->
<script>
  window.components.locale = { locale: 'cs-CZ' };   // every dropzone without its own locale: "1 file(s), 1,3 KB"
</script>
